# My Git Learning Notes

## 1. What is Git?
Git is a version control system used to track changes in files.

## 2. What is GitHub?
GitHub is an online platform where we can store Git repositories and collaborate with others.

## 3. Important Git Commands

- `git init` - Initialize a Git repository.
- `git status` - Check the current status of files.
- `git add .` - Stage changes.
- `git commit -m "message"` - Save a snapshot of changes.
- `git push` - Upload committed changes to GitHub.
- `git pull` - Fetch and integrate changes from GitHub.
